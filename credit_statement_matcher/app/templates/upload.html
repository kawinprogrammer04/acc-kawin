เลือกไฟล์ Statement

ระบบอ่าน PDF text layer ก่อน และใช้ OCR ภาษาไทยกับอังกฤษอัตโนมัติเมื่อเป็นไฟล์สแกนหรือข้อความเสีย

ขนาดสูงสุด 25 MB · PDF สูงสุด 50 หน้า · OCR ทำงานเบื้องหลัง จึงไม่หลุดด้วย 504 ระหว่างรอ

กำลังประมวลผล Statement

กำลังอัปโหลดไฟล์

  1. รับไฟล์และตรวจชนิดเอกสาร
  2. อ่าน text layer และโครงสร้างคอลัมน์
  3. ทำ OCR ไทย + อังกฤษเมื่อจำเป็น
  4. บันทึกรายการและจับคู่ให้อัตโนมัติ

กำลังสร้างงาน OCR · ใช้เวลาแล้ว 0 วินาที

เมื่อรับไฟล์แล้ว ระบบจะเปลี่ยนไปหน้าติดตามงานอัตโนมัติ

รูปแบบที่แนะนำ

หัวตารางขั้นต่ำ

Date / วันที่ Description / รายละเอียด Amount / จำนวนเงิน

เพิ่มคอลัมน์ Card Number / เลขบัตรได้ ระบบจะเก็บเฉพาะเลขท้าย 4 หลัก

SCB, Amex และ Krungsri จากไฟล์ตัวอย่างจะใช้ parser เฉพาะ พร้อมแจ้งแถว OCR ที่ควรตรวจทาน

อัปโหลด Screenshot (Ads)

เลือกรูปภาพ Screenshot จาก Ads ระบบจะอ่านข้อความ บันทึกหลักฐาน และลองจับคู่กับ Statement ให้อัตโนมัติ

สูงสุด 10 ไฟล์ · ไฟล์ละไม่เกิน 8 MB · ไม่เรียก Ollama และไม่ส่งรูปออกนอกเครื่อง

กำลังอ่านข้อความไทย + อังกฤษ

กำลังส่งภาพให้ AI วิเคราะห์

ใช้เวลาแล้ว 0 วินาที · ขึ้นอยู่กับจำนวนไฟล์

วิธีใช้

อัปโหลด Screenshot แบบ Flat

  1. เปิดโฟลเดอร์บัตรที่ต้องการ
  2. เลือกรูปภาพทั้งหมดในโฟลเดอร์ (Ctrl+A / Cmd+A)
  3. คลิก "เลือกรูปภาพ" แล้ว drop หรือ select ทุกไฟล์
  4. กด "อัปโหลดและตรวจให้อัตโนมัติ"
  5. ระบบเปิดแดชบอร์ดให้ตรวจผลเมื่อเสร็จ

ระบบดึง: วันที่, เวลา, ยอดเงิน, Invoice No., TxID, เลขบัตร · ข้อความที่อ่านได้เป็นข้อมูลอ่านอย่างเดียว
